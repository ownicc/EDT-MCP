Структурный diff BSL

Эксперимент: difftastic 0.71.0 + tree-sitter-bsl 0.1.7. Это статический просмотр, не окно EDT.

Подсветка кода взята из дерева tree-sitter; фон изменений — из JSON difftastic. Строки — зелёные, ключевые слова — фиолетовые. Режим сравнения не определяет, какие байты применять.

Известные ограничения: нет отдельного статуса «перемещено»; запросы внутри строк не разбираются как SDBL; JSON содержит только изменённые фрагменты; при ошибках разбора используется текстовый diff.
