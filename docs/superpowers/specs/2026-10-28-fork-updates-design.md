# Обновления форка EDT-MCP

Согласованная схема: установленный плагин проверяет релизы `ownicc/EDT-MCP`
и использует `https://ownicc.github.io/EDT-MCP/` как p2-источник.
Оригинал `DitriXNew/EDT-MCP` остаётся Git remote `upstream`; его изменения
переносятся в исходники форка, проверяются и выпускаются отдельным релизом.

Выбран собственный источник обновлений. Отключение всех проверок допустимо
временно; установка оригинальных релизов поверх форка теряет наши изменения.

Версии форка независимы: `v1.0.1`, `v1.0.2`, далее по возрастанию X.Y.Z.
Release workflow устанавливает эту же версию в bundle и feature через Tycho.
Отдельные суффиксы форка не нужны: текущий механизм читает три числовые части.

Публикация p2 вызывается непосредственно после успешного release job через
reusable workflow: событие от `GITHUB_TOKEN` не запускает другой workflow.
Ручная публикация принимает точный тег или последний стабильный релиз.
Черновики, предварительные релизы и неверные версии не публикуются.

У существующей установки EDT источник оригинала отключается отдельно.
Работающий EDT не закрываем и не меняем его файлы настроек за его спиной.
Сохраняем авторство и лицензию оригинального проекта.
