# Панель выбранного метода в BSL diff

## Согласованное направление

Пользователь выбрал вариант C: отдельная строка между общей панелью инструментов и кодом. Затем подтвердил охват всех видов изменений методов, включая добавленные и удалённые. Цель — сделать связь имени метода с действием Compare method очевидной и убрать зависимость этого действия от предварительного нажатия ↔.

Строка содержит подпись «Выбранный метод», имя, тип изменения, координаты старой и новой версий и кнопку «Сравнить метод». Выбор определяется щелчком или кареткой внутри метода с изменениями; ↔ остаётся переходом между положениями перемещённого метода.

| Состояние | Старая сторона | Новая сторона |
| --- | --- | --- |
| Изменён | Исходный метод | Изменённый метод |
| Перемещён | Метод до перемещения | Метод после перемещения |
| Перемещён и изменён | Исходный метод | Перемещённый метод с правками |
| Добавлен | Пусто, «Метод отсутствует» | Новый метод |
| Удалён | Удалённый метод | Пусто, «Метод отсутствует» |

Если метод не выбран, строка сообщает об этом, а действие недоступно. У отсутствующей стороны координата «—». Длинное имя сокращается многоточием с полным именем в подсказке. Изолированное сравнение остаётся read-only; Apply относится к основному review.

## Рассмотренные варианты

- A: компактная группа имени и кнопки в общей панели. Экономит высоту, но конкурирует за ширину с поиском и навигацией.
- B: имя внутри кнопки. Связь непосредственна, однако длинные имена затрудняют чтение действия.
- C: отдельная строка имени, статуса, координат и действия. Занимает дополнительную строку; выбран пользователем за явный контекст.
