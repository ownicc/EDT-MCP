# Поиск в BSL diff

Пользователь выбрал общую строку поиска по умолчанию по обеим сторонам.
Альтернатива — независимые поля над панелями — отклонена этим выбором.
Отдельный штатный диалог Eclipse не даёт согласованную общую строку с областью,
поэтому используем SWT-панель и существующий JFace Document search adapter.

Ctrl+F открывает строку; текст, область «Старая / Новая / Обе», регистр,
счётчик совпадений и кнопки назад/вперёд. Enter/F3 — вперёд,
Shift+Enter/Shift+F3 — назад; Esc закрывает строку. Концы обхода замыкаются.
Начальный режим — обе стороны, без учёта регистра. Совпадения в обеих версиях
считаются отдельно; порядок — отображаемая строка, затем старая/новая сторона.

Искать по настоящим исходникам, включая неизменённый код. Вставки выравнивания
не являются текстом. Переход выделяет совпадение и синхронно прокручивает панели;
не меняет выбранную пару методов. Работает в основной и method-only вкладках,
сохраняет read-only, существующие стили и original line numbers.

Отступ +/− исправляется отдельно по измеренному шрифту и числу цифр.
Явный выбор метода (`edt-mmh.7`) и панель методов (`edt-mmh.9`) запланированы,
но в этот поисковый шаг не входят. Поиск: `edt-mmh.8`.
